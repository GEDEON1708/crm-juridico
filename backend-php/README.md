# CRM Juridico API (Laravel)

Backend em migracao paralela ao Node atual. A conexao usa PostgreSQL e o banco `crm_juridico_php`, separado para evitar colisao com as tabelas Prisma existentes.

## Executar

Crie o banco `crm_juridico_php`, configure as credenciais em `.env` e rode:

```bash
composer install
php artisan key:generate
php artisan migrate
php artisan test
php artisan serve
```

O endpoint inicial fica em `http://127.0.0.1:8000/api/health`. Este scaffold ainda nao substitui `../backend`; migre e valide os contratos antes de mudar o `VITE_API_URL` do frontend.

## Conectar o frontend React

No arquivo `frontend/.env`, use:

```env
VITE_API_URL=http://localhost:8000/api
VITE_AUTH_MODE=session
```

Reinicie o Vite depois da alteracao. O exemplo do frontend continua apontando para Node e usando tokens ate essa troca ser feita deliberadamente.
